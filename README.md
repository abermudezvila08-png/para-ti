# Para Ti

Un regalo de VERBUM Tech Solution.

PWA: abre el enlace en Chrome y elige "Instalar aplicación".

## Regalo personalizable

- **Nombre en pantalla**: cada persona escribe su nombre en Ajustes → Personalización, y el reloj saluda con él ("Para Ti, María").
- **8 idiomas**: Español, English, Français, Português, Deutsch, 中文, العربية (con dirección derecha-izquierda) y Nederlands. Se elige en Ajustes y la fecha también se muestra en ese idioma.
- **Hora local**: el reloj y la fecha usan la hora del propio dispositivo de cada persona.
- **Google Calendar (opcional)**: en Ajustes → Notificaciones y calendario se pega un ID de cliente OAuth de Google y el reloj muestra los próximos eventos de esa persona. Todo se guarda solo en el dispositivo.
